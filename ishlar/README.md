### Qisqacha Xulosa:
1. **Dizayn:** 3 ta oltin qoida asosida unifikatsiya qilindi (Less is more, standart 16/20px o‘lchamlar, monoxrom 1.6px outline SVG).
2. **Asosiy Modullar:** Bosh Slayder, Startaplar katalogi & Leaderboard, Demo Day, Yangiliklar, Playbook, Talent Pool, Hakatonlar, Mentorlar, Ariza qabul qilish.
3. **Interaktivlik:** ⌘K Spotlight qidiruv, ovoz berishda konfetti, Ariza holatini tekshirish, QR-kodli chiptalar, Pitch Deck tomoshabini.
4. **Stek:** React 19 + TypeScript + Vite + Tailwind CSS + Framer Motion.
